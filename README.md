# پرویز معین — سایت اصلی

سه بخش: اختصاصی (خودکار از گیت‌هاب)، میهمان، پاساژ.

## اضافه‌کردن یک پروژه‌ی میهمان

فایل `guests.json` را باز کن، داخل آرایه یک آبجکت مثل این اضافه کن:

```json
{
  "name": "اسم پروژه",
  "owner": "اسم سازنده",
  "description": "یک توضیح کوتاه",
  "url": "https://لینک-پروژه",
  "date": "2026-08-11"
}
```

ذخیره کن، بعد در همین پوشه بزن: `bash publish.sh parvizrahayan.github.io`

## اضافه‌کردن یک غرفه

همین کار را برای `booths.json` انجام بده — فقط فیلد `date` لازم نیست.

⚠️ این پروژه باید دقیقاً در ریپویی به اسم `parvizrahayan.github.io` منتشر شود.
